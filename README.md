# Офис «Монолит»

Пиксельный бруталистский офис с пятью ИИ-агентами в чёрном. Они берут задачи, отвечают на вопросы, предлагают идеи, собирают вертикальные ролики для TikTok, а диджей Рико сводит треки по заказу.

Всё лежит в одном файле `index.html`, сборка не нужна.

## Как запустить на GitHub Pages

1. Создай репозиторий на GitHub и загрузи туда `index.html` и `README.md`.
2. Открой **Settings → Pages**, в **Source** выбери `Deploy from a branch`, ветку `main` и папку `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<твой-ник>.github.io/<репозиторий>/`.

Из терминала это делается так:

```bash
git init
git add index.html README.md
git commit -m "Офис Монолит"
git branch -M main
git remote add origin https://github.com/<твой-ник>/<репозиторий>.git
git push -u origin main
```

## Как подключить Claude

На GitHub Pages каждый посетитель подключает свой Claude сам: нажимает кнопку **«Claude»** в правом верхнем углу и вставляет свой API-ключ с [console.anthropic.com](https://console.anthropic.com).

- Ключ хранится только в браузере посетителя и уходит напрямую в Anthropic. На твой сервер он не попадает, потому что сервера нет.
- Запросы оплачиваются со счёта того, чей ключ.
- Модель по умолчанию `claude-opus-5-5`, в настройках можно выбрать Sonnet 5.5 или Haiku 5.5.
- Для Opus и Sonnet включён серверный фолбэк Anthropic (`fallbacks: "default"`). Если модель откажет по соображениям безопасности, запрос автоматически уйдёт на подходящую модель.

## Где всё сохраняется

- **На GitHub Pages:** в IndexedDB браузера, то есть состояние офиса, задачи, идеи, чаты, проекты, треки и загруженные файлы. При повторном заходе с того же браузера всё на месте. На другом устройстве офис будет свой.
- **Внутри Claude (артефакт):** у владельца в облачной базе Claude, у гостей в их браузере.

## Что работает только внутри Claude

Очередь задач для **Claude Code**: галочка «Отдать Claude Code» у задачи. Claude Code читает эту очередь через базу артефакта, поэтому в версии на GitHub Pages очереди нет.
